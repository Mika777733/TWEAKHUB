TweakHub — оптимизация Windows 10/11 без установки.

Новое:
• Главная: загрузка CPU/GPU/RAM в реальном времени и оптимизация в одно нажатие
• Твики GPU: настройки драйвера NVIDIA (питание, фильтрация, низкая задержка), ULPS для AMD, MPO, TDR, HAGS
• Драйверы: версия и дата драйвера видеокарты, ссылки на официальные сайты
• Удаление лишних предустановленных приложений
• Новые твики сети и Windows, тема «Ночное стекло»

Скачайте TweakHub.exe и запустите. Перед изменениями создаётся точка восстановления, всё можно откатить.
